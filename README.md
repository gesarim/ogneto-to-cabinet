# Огнето — кабинет коммерческих предложений

Веб-сервис для расчёта стоимости технического обслуживания огнетушителей и управления коммерческими предложениями. Интерфейс на русском языке.

## Возможности

- Обзор и список КП с поиском и статусами.
- Создание и редактирование КП: объект, условия доступа, группы огнетушителей, резерв, маршруты и тариф.
- Предварительный расчёт времени первичной и второй проходки, выборки по марке, логистики и стоимости.
- Настройка норм, цен, тарифов и шаблона КП.
- Постоянное хранение КП в Cloudflare D1, клиентская ссылка и скачивание PDF.

Актуальный сайт: https://ogneto-to-cabinet-20261027.gesarim.chatgpt.site

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run db:generate
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_talented_firestar.sql
npm start
```

Локальный адрес после запуска: `http://127.0.0.1:8787`.

## Важно

Сейчас кабинет опубликован без авторизации. Любой посетитель сайта может видеть и изменять КП. Не используйте его для конфиденциальных данных до добавления контроля доступа. Цены по умолчанию демонстрационные и редактируются в настройках.

Запланированная функция автоматического расчёта сроков проверки, перезарядки и замены описана в `docs/roadmap.md` и пока не реализована.
